# SCADA 機櫃（SoW V6 附錄 D）— Dynamo 產生、自動放進機房、逐站匯出 NWC / RVT

## 檔案
| 檔案 | 用途 |
|---|---|
| `SCADA_Racks_SoW_V6.csv` | 36 台機櫃資料＋定位設定，可用 Excel 修改 |
| `SCADA_Racks_SoW_V6.dyn` | Dynamo 圖檔（Revit 2025 / Dynamo 3.3，CPython3） |
| `scada_racks.py` | .dyn 內嵌的同一份程式，.dyn 打不開時可貼到 Python Script 節點 |
| `族群\SCADA_機櫃_<寬>x<深>x<高>.rfa` | 執行時自動產生：每種尺寸一個電氣設備族群，類型 = 機櫃類型 |
| `建築模型房間快取.json` | 執行後自動產生：各建築模型的房間座標與共用座標，模型檔沒變就不重開 |

## 使用步驟
1. Revit 2025 開一個空白專案（只當執行環境，機櫃不會建在這裡）。
2. 管理 → Dynamo → 開啟 `SCADA_Racks_SoW_V6.dyn`，按「執行」。
3. 第一次執行會在背景開啟各站建築模型讀房間（SB12 約 800 MB，會比較久）；之後模型沒更新就直接用快取。
4. 結果每站一行，例如 `03_P1_SB10: 2 台（房間 2）；已讀取 DN-AR-SB10-0000 V17.rvt -> NWC -> RVT`。
   放不進房間的機櫃會另列一行說明原因。
5. Navisworks：開各站整合模型 NWD，再「附加」對應的 NWC，機櫃會依共用座標自動對齊。

## 定位怎麼運作（CSV 的定位欄位）
| 欄位 | 說明 |
|---|---|
| `建築模型` | 該站建築 RVT 路徑（相對於 CSV 所在資料夾）。空白 = 放在原點 |
| `房間關鍵字` | 以 `|` 分隔，依順序比對房間名稱或編號，先比到的優先，例如 `SCADA|通訊號誌|通訊` |
| `X偏移mm`、`Y偏移mm` | 在自動位置上再平移（模型內部座標方向），手動微調用 |
| `旋轉度` | 以機櫃中心逆時針旋轉的角度 |

- 機櫃中心放在房間的「位置點」，底部在房間樓層高程；同一房間多台會沿 X 方向並排。
- 每站 RVT 會套用該建築模型的共用座標，NWC 以共用座標匯出。
- **重跑時保留**：腳本只讀 CSV、不回寫，你填的偏移、旋轉、關鍵字都會保留。
- 實際配對到哪個房間寫在參數 `SCADA_定位來源`（Navisworks「自訂」頁籤可看），比錯就改 `房間關鍵字` 重跑。

## 目前有建築模型的站
SB10、SB11、SB12、SB14、SB15（由 `..\建築模型\` 與 `..\00_Mainline\` 取得）。
SB13、第二期各站、機廠行政大樓與 TSS 沒有含房間的建築模型，維持放在原點；有模型後填入 `建築模型` 欄即可。

## Navisworks 看得到的資料
點選機櫃 → 屬性面板 → **自訂** 頁籤：所有 `SCADA_` 參數（空值不顯示）。
「元素」頁籤有名稱、標記（＝編號）、備註。

## 執行前檢查 CSV（不需要 Revit）
在工具資料夾執行，只讀 CSV 與 `建築模型房間快取.json`，不寫任何檔案：
```
python validate_racks.py
```
列出 [錯誤]（缺欄、缺編號、編號重複、尺寸或偏移不是有限數字、同群組建築模型不一致等）與 [警告]（備註「待確認」、房間關鍵字在快取中沒命中、找不到建築模型）。有錯誤時 exit code = 1。

單元測試：
```
python -m unittest discover -s tests -v
```

## 注意
- 機櫃為電氣設備**族群**（固定尺寸方塊，由 `公制電氣設備.rft` 產生），每種尺寸一個族群、每種機櫃類型一個類型；尺寸不是可拉伸參數，改尺寸請改 CSV 重跑。
- 族群可直接載入其他專案使用（`族群\` 資料夾）。
- 編號（如 `SB10-COMS-RTU-01`）是暫訂命名，不是業主正式設備編碼。
- PLC 機櫃：附錄 D 彙總表寫 1 座、明細 17 座，CSV 依明細建 17 台，`SCADA_備註` 標「數量待確認」。
- 預設房間關鍵字：COMS RTU 機櫃 `SCADA|通訊號誌|通訊`（五站都配到「通訊/SCADA設備室」）；
  TSS PLC 機櫃 `牽引|TSS`（SB10 F351、SB11 F115 TSS、SB14 F334、SB15 F314「牽引動力配電室」，
  SB12 F446「牽引動力變電室」）。目前 5 站 10 台全部配到房間，執行後可在 `SCADA_定位來源` 確認。
- 對齊前提：各站整合模型 NWD 的 NWC 是以共用座標匯出；若整合模型用的是內部原點，位置會差一個共用座標的位移。
- 共用參數檔在 `NWC\SCADA_SoW_V6_SharedParameters.txt`；執行後會還原你原本設定的共用參數檔。
